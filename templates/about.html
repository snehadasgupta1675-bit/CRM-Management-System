ABOUT THE PROJECT

CRM Connect

A Django-based Customer Relationship Management web application created to demonstrate structured customer data management, CRUD operations and a responsive web interface.

CRM

Customer Relationship Management

A structured approach to storing, organizing and maintaining information about customer relationships.

PROJECT PURPOSE

Why this application was created

The project brings common customer-management tasks into one web application instead of relying on separate lists or scattered records. It provides a practical example of how a Django application can connect a user interface to a relational database.

The system is designed around clarity: customer information is entered through forms, stored in SQLite, managed through CRUD operations and presented through dedicated pages.
